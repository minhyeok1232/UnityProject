## 🔎 프로젝트 소개
- **장르** : Built-In(PC) 3D MMORPG
- **IDE** : Unity 3.18f, Visual Studio 2022     
- **목적** :  
  - 사용자에게 몰입감 있는 비주얼을 제공하기 위해 대형 3D Asset으로 제작
  - 사용자에게 역동적인 연출과 부드러운 카메라 움직임을 제공 
  - 사용자에게 끊김 없는 플레이 경험을 제공
  - 일관된 시스템 구조와 효율적인 리소스 관리 구현
